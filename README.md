# Аналог Figma для рынков с ограниченным доступом

Проект по созданию совместного редактора интерфейсов (аналог Figma) для стран, где Figma
становится недоступной. Ключевая модель — **локальный SaaS внутри целевой страны**:
резидентность данных, локальные платежи, независимость от внешней (подсанкционной)
инфраструктуры.

## Структура репозитория

| Каталог | Назначение |
|---|---|
| [`docs/`](docs/) | Документы нашего сервиса: продукт, сценарии, функциональность, архитектура, роадмап, инфраструктура. |
| [`src/`](src/) | Анализ Figma и конкурентов — исходный материал и обоснование решений. |
| [`.claude/agents/`](.claude/agents/) | Определения субагентов команды (продукт + разработка). |
| [`.claude/memory/`](.claude/memory/) | Память проекта между сессиями (уроки, прогресс). |
| [`CLAUDE.md`](CLAUDE.md) | Операционные правила для работы с Claude Code. |
