# CLAUDE.md

Операционные правила проекта. Держим файл коротким (~цель ≤120 строк): каждая строка
заслуживает места. Детали — в `docs/`, не дублируем их здесь.

## 1. Что за проект
Аналог Figma — совместный редактор интерфейсов для стран, где Figma недоступна.
Модель — **локальный SaaS в стране** (резидентность данных, локальные платежи).
Документация — **на русском**.

## 2. Структура репозитория
- `docs/` — документы нашего сервиса (продукт, сценарии, функциональность, архитектура,
  роадмап, инфраструктура). `docs/00-глоссарий-и-решения.md` — журнал решений (ADR) + словарь.
- `src/` — анализ Figma и конкурентов (исходный материал, обоснование решений).
- `.claude/agents/` — определения субагентов команды.
- `.claude/memory/` — память проекта (`lessons.md`, `progress.md`).

## 3. Язык и стиль
- Русский; англоязычный термин — в скобках при первом упоминании.
- Единая терминология — из `docs/00-глоссарий-и-решения.md`. Новый термин → сначала туда.

## 4. Рабочий процесс
- Для задач в 3+ шага — сначала план-режим.
- Используем субагентов для изоляции контекста (по одному фокусу на агента).
- Хэндофф между агентами — **через файлы**. **Не редактируй чужой owned-файл** (владения —
  в `.claude/agents/`); кросс-файловые вопросы — через лид-оркестратора.

## 5. Ключевые решения (полностью — в `docs/00` и `docs/04`)
- MVP = редактор + real-time коллаборация + dev-хэндофф (ADR-2).
- Развёртывание = локальный SaaS, старт с моно-сервера (ADR-3, ADR-4).
- Синхронизация = server-authoritative property-level LWW + fractional indexing (ADR-6).

## 6. Git / PR
- Рабочая ветка: `claude/repo-cleanup-DLg23`.
- Коммиты — описательные, по-русски. PR — ready for review (не draft).
- `git push -u origin claude/repo-cleanup-DLg23`.

## 7. Память проекта (подробно — `docs/00` и `.claude/memory/`)
- **Старт сессии:** прочитать `CLAUDE.md` → `.claude/memory/progress.md` → `docs/00`.
- **В ходе работы:** продукт/арх-решение → ADR в `docs/00`; урок/ошибка → `lessons.md`.
- **Конец значимого шага:** обновить `progress.md` (сделано / дальше) и закоммитить.
- Память лаконична: урок — одной строкой-правилом; прогресс — чек-лист.
