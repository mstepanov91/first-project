Обзор проекта · MVP

Совместный редактор интерфейсов

Аналог Figma для стран, где сервис становится недоступен. Модель — локальный SaaS внутри целевой страны: резидентность данных, локальные платежи и независимость от внешней (подсанкционной) инфраструктуры.

MVP: редактор + коллаборация + хэндофф Рендерер: TypeScript + WebGL Синхронизация: server-authoritative LWW Старт: моно-сервер

Что делаем

Когда Figma уходит с рынка, команды теряют доступ к файлам, оплате и совместной работе. Мы строим самодостаточную замену, развёрнутую внутри страны. Ценность — в четырёх опорах:

🔓 Доступность

Работает там, где Figma заблокирована: инфраструктура и домены — локальные, без зависимости от внешних провайдеров.

🛡️ Резидентность данных

Файлы и метаданные хранятся в юрисдикции целевой страны; изоляция арендаторов и контроль доступа.

💳 Локальные платежи

Подписка через локальные платёжные провайдеры; capped-тарифы вместо дорогой оплаты per-seat.

🌐 Локализация

Полностью русскоязычный интерфейс с первого релиза — то, чего нет у Figma (только English UI).

Прецеденты модели: Penpot (open-source, self-hosted, владение данными) и Pixso/MasterGo (выросли на рынках с ограниченным доступом к Figma).

Основная функциональность MVP

Ядро продукта: векторный редактор UI + совместная работа в реальном времени + передача дизайна разработчику. Whiteboard, презентации и AI — за рамками MVP (в роадмапе).

✏️ Редактор

Фреймы, формы, текст, изображения; авто-лэйаут; компоненты, экземпляры и варианты; стили и переменные (дизайн-токены); вектор, выравнивание, констрейнты.

E2 · ADR-9

👥 Мультиплеер

Real-time совместное редактирование, присутствие (курсоры, выделения), разрешение конфликтов по property-level last-writer-wins.

E3 · ADR-6

💬 Комментарии и ревью

Обсуждения на холсте, треды, упоминания, статусы — обратная связь без выхода из файла.

E4

🧑‍💻 Dev-хэндофф

Inspect, измерения, экспорт ассетов, значения токенов и базовый CSS-сниппет. Генерация кода под фреймворки — позже.

E5 · ADR-10

📥 Импорт .fig

Перенос файлов из Figma как трек миграции (с отчётом о покрытии). Технически рискован — вне критического пути MVP.

E6 · ADR-7

Ключевые этапы роадмапа

Принцип: риск раньше объёма; инфраструктура догоняет аудиторию (тиры T0→T2). Тиры переключаются по факту нагрузки, а не по номеру фазы.

Дифференциация vs конкуренты

Figma — эталон опыта, но недоступна и дорога; Penpot силён открытостью, но слабее по коллаборации; Pixso/MasterGo показали плейбук для рынков с ограничениями. Наша ниша — пересечение доступности, резидентности и локализации.

Резидентность данных в стране✔ да✘ нет✔ self-host~ приватный деплой

Оценка инфраструктуры по тирам аудитории

Арендованные облачные серверы локальных провайдеров. Старт — с минимума (моно-сервер), масштабирование по триггерам нагрузки. Цифры — ориентир (диапазон ₽/мес), точный счёт — по калькулятору провайдера.
