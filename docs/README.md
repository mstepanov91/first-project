# Документация сервиса

Документы продукта — аналога Figma для рынков с ограниченным доступом. Модель развёртывания —
локальный SaaS в целевой стране (резидентность данных, локальные платежи, независимость от
внешней инфраструктуры).

Каждый документ начинается с краткого бизнес-резюме, далее — детализация для исполнения.

## Содержание

| Документ | О чём |
|---|---|
| [00 — Глоссарий и решения](00-глоссарий-и-решения.md) | Единый словарь терминов и журнал ключевых решений (ADR). Источник правды. |
| [01 — Описание продукта](01-описание-продукта.md) | Видение, проблема, ценностное предложение, сегменты, бизнес-модель, дифференциация. |
| [02 — Продуктовые сценарии](02-продуктовые-сценарии.md) | Персоны, jobs-to-be-done, ключевые пользовательские сценарии. |
| [03 — Функциональность](03-функциональность.md) | Функциональная спецификация MVP (эпики, истории, приёмочные критерии). |
| [04 — Архитектура](04-архитектура.md) | Техническая архитектура: рендеринг, модель документа, синхронизация, сервисы, деплой. |
| [05 — Роадмап](05-роадмап.md) | Верхнеуровневый роадмап фазами: цели, фичи, риски, критерии готовности. |
| [06 — Инфраструктура и стоимость](06-инфраструктура-и-стоимость.md) | Варианты инфраструктуры и оценка ресурсов/стоимости по тирам аудитории. |
| [07 — Юридическая оценка](07-юридическая-оценка.md) | Правомерность аналога и риски: авторское право, патенты, товарные знаки, reverse engineering, OSS-лицензии, санкции и персональные данные, матрица рисков. |
| [08 — Инвестиции и выход](08-инвестиции-и-выход.md) | Когда выходить на инвесторов (раунды по тирам) и стратегия продажи бигтехам; тайминг M&A. |

## Связь с анализом

Решения в этих документах опираются на анализ Figma и конкурентов в каталоге
[`../src/`](../src/). Ключевые архитектурные решения (`04`) ссылаются на соответствующие
разделы анализа.
