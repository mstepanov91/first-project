# Уроки проекта

> Корректировки и ошибки → правила «не повторять». Одна строка — одно правило.
> Пополняется сразу после правки/ошибки (практика самоулучшения).

- WebFetch в этом окружении отдаёт 403 — для веб-рисёрча использовать WebSearch, а не WebFetch.
- Документация только на русском; англоязычный термин — в скобках при первом упоминании.
- Не редактировать чужой owned-файл субагента — координация через лид-оркестратора.
- Память и любые артефакты должны быть закоммичены: контейнер эфемерный.
