# 02. Продуктовые возможности Figma

> Источники — в [`06-источники.md`](./06-источники.md). Анализ по публичным материалам.
> Терминология — по [`docs/00`](../docs/00-глоссарий-и-решения.md).

Разбор по основным поверхностям (surfaces): редактор, прототипирование, комментарии/ревью,
Dev Mode, библиотеки и переменные, и обзорно — FigJam/Slides/Make.

## 2.1. Редактор (Figma Design)

### Фреймы и контейнеры
- **Фрейм (Frame)** — основной контейнер-узел (аналог артборда). Может вкладываться, иметь
  фон, обрезку (clip content), констрейнты и сетки.
- **Холст (Canvas)** — бесконечная рабочая область; на одной странице (Page) может быть много
  фреймов.

### Авто-лэйаут (Auto Layout)
Flex-подобная авто-раскладка дочерних узлов: направление (горизонталь/вертикаль), отступы
(padding), зазоры (gap), выравнивание, режимы роста (hug / fill / fixed). Это основа
адаптивных компонентов и снижения ручного позиционирования. В 2025 добавлена система **Grid**
для двумерных сеточных раскладок с трансляцией в CSS Grid.

### Компоненты, варианты, экземпляры
- **Компонент (Component)** — переиспользуемый узел-шаблон.
- **Вариант (Variant)** — версия компонента внутри набора (variant set): состояния, размеры,
  типы (например, кнопка default/hover/disabled).
- **Экземпляр (Instance)** — копия компонента, наследующая свойства; допускает переопределения
  (overrides) и **свойства компонента (component properties)** — boolean, text, instance swap,
  variant.

### Стили
- **Стиль (Style)** — именованный набор свойств: цвет/заливка, текст (typography), эффект
  (тени/блюр), сетка раскладки. Стили переиспользуются и публикуются в библиотеках.

### Векторные инструменты и операции
- Векторный редактор (Vector Networks — у Figma нетривиальная модель, где точка может иметь
  больше двух рёбер), перо, кривые Безье.
- **Булевы операции (Boolean operations)** — union, subtract, intersect, exclude.
- **Figma Draw** (2025) — расширенный набор иллюстративных инструментов поверх векторного
  движка ([Config 2025](https://www.figma.com/blog/config-2025-recap/)).

### Сетки и констрейнты
- **Констрейнты (Constraints)** — привязка узла к краям/центру родителя при изменении размера
  (left/right/top/bottom/center/scale).
- **Сетки раскладки (Layout grids)** — колоночные/строчные/квадратные сетки внутри фрейма.

## 2.2. Прототипирование (Prototyping)

- **Связи между фреймами** — соединения, описывающие переходы по экранам.
- **Триггеры (Triggers)** — On click, On drag, While hovering, While pressing, Key/Gamepad,
  After delay, Mouse enter/leave.
- **Действия и переходы** — Navigate to, Open overlay, Swap, Back, Scroll to, Open link;
  анимации (animation): Instant, Dissolve, Move/Push/Slide, Smart Animate (интерполяция между
  состояниями по совпадающим слоям).
- **Интерактивные компоненты** — состояния внутри variant-набора как мини-прототип.

> **Оценка автора.** Smart Animate и интерактивные компоненты — сильная сторона Figma;
> у многих конкурентов (Penpot, частично Sketch) прототипирование слабее (см. `07`).

## 2.3. Комментарии и ревью

- **Комментарии (Comments)** — привязанные к точке на холсте или к конкретному узлу, треды,
  @-упоминания, эмодзи, реакции, разрешение (resolve).
- **Уведомления** о новых комментариях и изменениях; интеграции (Slack и др.) через вебхуки.
- **Версии и ветки (branching)** — на старших тарифах: ветвление файла и слияние, ревью
  изменений.

## 2.4. Dev Mode (хэндофф для разработчиков)

Dev Mode — отдельная поверхность для разработчиков
([Figma Dev Mode](https://www.figma.com/dev-mode/)):

- **Inspect / измерения** — размеры, отступы, цвета, типографика по клику на узел; расстояния
  между элементами.
- **Код-сниппеты** — автогенерация CSS, iOS (SwiftUI), Android (Jetpack Compose); плагины
  расширяют генерацию.
- **Переменные/токены в коде** — отображение значений переменных с соответствующим синтаксисом
  кода (read-only Variables-модал в Dev Mode —
  [Help: Variables in Dev Mode](https://help.figma.com/hc/en-us/articles/27882809912471-Variables-in-Dev-Mode)).
- **Экспорт ассетов** — PNG/JPG/SVG/PDF с настройкой масштабов и суффиксов.
- **Аннотации (Annotations)** — пометки спецификаций прямо на дизайне; статусы (Ready for dev),
  обзор «что готово/что изменилось».
- **Сравнение версий / code layers** — отслеживание изменений между ревизиями, чтобы
  разработчик не строил по устаревшему дизайну
  ([designilo: Dev Mode](https://designilo.com/2025/07/23/how-to-use-figmas-dev-mode-to-bridge-the-gap-between-design-and-code/)).

> **Связь с MVP.** Dev-хэндофф входит в ядро MVP (ADR-2). Минимум: inspect, измерения, экспорт
> ассетов, отображение токенов. Генерация кода и аннотации — желательно, но второстепенно.

## 2.5. Библиотеки и переменные

### Библиотеки (Libraries)
Публикуемые наборы компонентов, стилей и переменных, переиспользуемые между файлами и
командами; обновления распространяются на экземпляры (с подтверждением).

### Переменные (Variables) и дизайн-токены
- **Переменная (Variable)** — именованное значение (color, number, string, boolean).
- **Дизайн-токен (Design token)** — атомарное значение дизайн-системы (цвет, отступ, радиус).
- **Режимы/темы (Modes)** — у коллекции переменных может быть несколько режимов (light/dark,
  бренды, плотность), что позволяет переключать тему всего макета.
- Переменные связываются со свойствами узлов и видны в Dev Mode с код-синтаксисом
  ([Figma: Design tokens](https://www.figma.com/resource-library/design-tokens/)).

> **Оценка автора.** Переменные с режимами — критичная фича для дизайн-систем; в нашем продукте
> их стоит закладывать в модель данных с самого начала (см. `04`), даже если UI-редактор тем
> придёт позже MVP.

## 2.6. Обзорно: FigJam, Slides, Make/AI

- **FigJam** — онлайн-доска: стикеры, фигуры, коннекторы, шаблоны, таймер, голосования;
  расширяется виджетами (Widget API).
- **Figma Slides** — презентации на движке Figma: слайды, темы, интерактивные элементы,
  совместное ведение.
- **Figma Make** — prompt-to-code: генерация рабочих прототипов/приложений по тексту и/или
  существующему дизайну ([Config 2025](https://www.figma.com/blog/config-2025-press-release/)).
- **Figma Sites / Buzz** — публикация сайтов и брендового контента (см. `01`).

> Для нашего MVP эти поверхности — вне охвата (ADR-2); фиксируем как ориентир роадмапа.
