# 01. Обзор продукта Figma

> Источники — в [`06-источники.md`](./06-источники.md). Анализ по публичным материалам.

## 1.1. Что такое Figma

Figma — облачный (cloud-based) редактор интерфейсов и платформа для совместной работы над
дизайном. Ключевое отличие от исторических конкурентов (Sketch, Adobe XD) — **работа целиком
в браузере** через единый общий документ, к которому одновременно подключаются несколько
участников в реальном времени (мультиплеер / multiplayer). Это снимает обмен файлами и делает
«источником правды» один онлайн-документ.

Figma основана в 2012 году (Дилан Филд и Эван Уоллес), публичный запуск редактора — 2016 год.
В 2022 году Adobe объявила о покупке Figma за ~$20 млрд; в декабре 2023 года сделка была
**отменена** из-за антимонопольных возражений регуляторов в ЕС и Великобритании. В 2024 году
Figma вернула AI-функции и расширила линейку, а в **2025 году вышла на IPO** (биржа NYSE) —
см. [Wikipedia: Figma](https://en.wikipedia.org/wiki/Figma).

## 1.2. Продуктовая линейка

К 2025 году Figma из «одного редактора» превратилась в платформу из нескольких продуктов
(значительная часть представлена/расширена на конференции **Config 2025**, май 2025 —
[Config 2025 recap](https://www.figma.com/blog/config-2025-recap/),
[пресс-релиз Config 2025](https://www.figma.com/blog/config-2025-press-release/)):

| Продукт | Назначение | Статус |
|---|---|---|
| **Figma Design** | Основной редактор UI/UX: векторная графика, фреймы, компоненты, прототипы. | Зрелый, ядро. |
| **FigJam** | Онлайн-доска (whiteboard) для воркшопов, диаграмм, брейнштормов. | Зрелый. |
| **Dev Mode** | Режим хэндоффа (handoff) для разработчиков: inspect, измерения, токены, экспорт. | Зрелый (платный seat). |
| **Figma Slides** | Инструмент презентаций на базе движка Figma. | GA с 2024. |
| **Figma Make** | Генерация кода/приложений по текстовому промту (prompt-to-code, AI). | Анонс Config 2025. |
| **Figma Sites** | Дизайн и **публикация веб-сайтов** прямо из Figma (конкурент Framer/Webflow). | Анонс Config 2025. |
| **Figma Draw** | Расширенные векторные/иллюстративные инструменты внутри Figma Design. | Анонс Config 2025. |
| **Figma Buzz** | Создание брендового контента в масштабе для маркетинг-команд. | Анонс Config 2025. |

Дополнительно на Config 2025 представлена система **Grid** — продвинутая сеточная раскладка с
прямой трансляцией в CSS Grid в Dev Mode
([DEV: Config 2025](https://dev.to/smartterss/figma-sites-figma-make-figma-buzz-grid-figma-draw-everything-that-figma-announced-in-config-3c57)).

> **Связь с нашим проектом (ADR-2).** MVP нашего аналога — это **ядро**: векторный редактор UI
> + real-time коллаборация + dev-хэндофф (то есть аналоги Figma Design, мультиплеера и Dev
> Mode). FigJam, Slides, Sites, Make/AI — вне MVP, в роадмапе «Будущее».

## 1.3. Целевые пользователи

- **Дизайнеры (product/UX/UI)** — основная аудитория: проектируют экраны, дизайн-системы,
  прототипы.
- **Разработчики (frontend/mobile)** — через Dev Mode получают спецификации, токены, код-сниппеты.
- **Продакт-менеджеры (PM), исследователи, контент-дизайнеры** — комментарии, ревью, FigJam,
  Slides.
- **Маркетинг/бренд-команды** — Figma Buzz, шаблоны.

Ценность Figma — в **общем пространстве** для всех ролей вокруг одного источника правды.

## 1.4. Бизнес-модель и тарифы

Модель — **подписка по местам (seat-based SaaS)**. В 2025 году Figma провела крупную
**реформу тарификации** (вступила в силу при продлении подписки на/после 11 марта 2025):
вместо отдельных мест под каждый продукт (Design / Dev Mode / FigJam отдельно) введены
**унифицированные типы мест** — Full / Dev / Collab / View
([Figma Help: обновления тарификации](https://help.figma.com/hc/en-us/articles/27468498501527-Updates-to-Figma-s-pricing-seats-and-billing-experience)).

Ориентировочные цены (план Professional / Organization, по публичным обзорам):

| Тип места | Назначение | Цена (annual) |
|---|---|---|
| **Full** | Полный доступ к дизайну/прототипам. | **$15/мес** (выросло с ~$12) |
| **Dev** | Dev Mode (разработчики). | ~$12/мес |
| **Collab** | Комментарии/FigJam без редактирования дизайна. | ~$3/мес |
| **View** | Просмотр. | бесплатно |

Ключевой факт для нашей ценовой стратегии: **базовый Full-seat подорожал с ~$12 до $15** за
редактора в месяц в 2025 году
([UserJot: Figma pricing](https://userjot.com/blog/figma-pricing-2025-plans-seats-costs-explained),
[PricingSaaS](https://newsletter.pricingsaas.com/p/inside-figmas-pricing-evolution)).
Бесплатный тариф (Starter) ограничен (например, ~3 совместными файлами) — это частый повод
для миграции на бесплатные альтернативы (см. `07`).

## 1.5. Доля рынка

По экспертным обзорам, Figma занимает доминирующее положение в дизайне продуктов — около
**~70% среди tech-команд** (оценка по обзорам сообщества; точные цифры варьируются между
источниками). Это создаёт сильный сетевой эффект: дизайн-системы, обучение, найм и плагины
выстроены вокруг Figma — что одновременно её ров (moat) и точка уязвимости для рынков, где
она недоступна.

## 1.6. Краткая история (вехи)

- **2012** — основание (Д. Филд, Э. Уоллес).
- **2016** — публичный запуск браузерного редактора.
- **2017–2019** — компоненты, библиотеки команд, плагины, Auto Layout.
- **2021** — запуск FigJam (whiteboard).
- **2022** — анонс покупки Adobe (~$20 млрд).
- **2023** — миграция рендеринга на **WebGPU**; **отмена** сделки с Adobe.
- **2024** — Dev Mode, Figma Slides, возврат AI-функций.
- **2025** — реформа тарифов; **Config 2025** (Sites, Make, Buzz, Draw, Grid); **IPO**.

> **Контекст ADR-1.** Для ряда стран Figma стала недоступна (санкции/блокировки). Известный
> прецедент — разрыв Figma с DJI, после которого китайские поставщики (Pixso и др.) активно
> предложили замену (см. `07` и
> [Yicai Global](https://www.yicaiglobal.com/news/pixso-other-chinese-software-firms-offer-their-services-after-us-figma-cuts-ties-with-dji)).
> Это и есть рыночное окно для нашего продукта.
