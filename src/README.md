# Раздел `src/` — Аналитика Figma и конкурентов

> **Дисклеймер.** Все материалы этого раздела составлены **исключительно по публичным
> источникам**: инженерному блогу Figma, официальной документации для разработчиков
> (developer docs), экспертным обзорам и сравнениям. Проприетарный код не воспроизводится —
> приводится только публично описанный анализ архитектуры и поведения продукта. Все
> URL-источники собраны в [`06-источники.md`](./06-источники.md). Документы написаны на
> русском языке; англоязычный термин приводится в скобках при первом упоминании, терминология
> согласована с [`../docs/00-глоссарий-и-решения.md`](../docs/00-глоссарий-и-решения.md).

## Назначение

Раздел даёт командам продукта и инженерии единую картину того, *что* представляет собой
Figma, *как* она устроена технически и *чем* отличаются конкуренты — чтобы обоснованно
проектировать наш аналог для рынков, где Figma недоступна (см. ADR-1).

## Связь с решениями проекта

Аналитика опирается на принятые ADR из `../docs/00-глоссарий-и-решения.md` и поставляет
фактуру для них: ADR-5 (рендеринг) питается из `03`, ADR-6 (протокол синхронизации) — из `03`
и `04`, ADR-7 (импорт `.fig`) — из `07`. Новые факты, влияющие на решения, предлагаются
лид-оркестратору для внесения в `docs/00`.
